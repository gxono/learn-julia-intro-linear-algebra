# learn-julia-intro-linear-algebra

Repositorio personal para aprender Julia desde cero, con foco principal en `LinearAlgebra`.

## Qué hace falta instalar

- Julia (se puede instalar desde la Microsoft Store)
- VS Code (también desde la Microsoft Store)
- La extensión "Julia" dentro de VS Code

Si nunca instalaste nada de esto ni sabés qué es una terminal, arrancá directamente por [lessons/00-instalacion-y-entorno.md](lessons/00-instalacion-y-entorno.md), que está pensada paso a paso para alguien que nunca programó.

## Estructura del repo

- `lessons/`: lecciones en Markdown con teoría y ejemplos
- `exercises/`: ejercicios para practicar
- `src/`: archivos auxiliares e ejemplos de código
- `scratch/`: zona libre para probar ideas y experimentar

## Cómo trabajar con las lecciones

La idea es leer una lección, probar los ejemplos en el REPL de Julia y después resolver los ejercicios de la carpeta `exercises/`.

## Área de prueba libre

La carpeta `scratch/` sirve para romper cosas sin miedo y probar ideas sueltas.
